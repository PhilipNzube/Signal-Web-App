# Signal Web App

Signal is a web-based dashboard concept for a financial signals and market-information platform. It brings together signal feeds, market categories, analysis, sentiment updates, events, and learning content in one interface.

The application is built with React and Material UI, with dashboard pages connected to a remote API for account and platform data.

## Features

- **Account access:** sign-in, registration, password recovery, and password-change screens.
- **Dashboard:** account overview with balance and signal summary information.
- **Market sections:** dedicated areas for cryptocurrency, forex, and stocks.
- **Signals and analysis:** signal cards, analysis views, and signal-author pages.
- **Market sentiment:** sentiment feed with detail views and support for submitting event-related information.
- **Events:** event listing, search, and event detail pages.
- **Learning content:** course listing and course detail screens.
- **Account utilities:** profile settings, package views, deposit history, and referral pages.
- **Responsive interface:** Material UI components and layouts designed to adapt to different screen sizes.
- **Feedback and notifications:** in-app messages using notistack.

## Tech stack

| Technology | Role |
|---|---|
| React 18 | UI and application structure |
| React Router | Client-side navigation |
| Material UI | Interface components and styling |
| Axios | HTTP requests to the platform API |
| notistack | Snackbar notifications |
| Create React App | Development server and production build tooling |
